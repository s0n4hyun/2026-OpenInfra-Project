# OpenInfra Lab Kit | Learning Log

2026학년도 2학기 종합설계프로젝트1에서 진행하는 OpenInfra Lab Kit 프로젝트의 개인 학습 및 실습 기록입니다.

OpenStack과 Kubernetes를 기반으로 클라우드 인프라를 학습하고, Terraform 등의 자동화 도구를 활용한 실습 과정을 정리합니다.

## 학습 내용

| 분야 | 주요 학습 내용 |
|---|---|
| Git / GitHub | Fork, Clone, Branch, Commit, Push, Pull Request |
| Sphinx / tox | rST 문서 작성, 정적 HTML 문서 빌드 |
| Terraform | IaC 개념, 기본 문법, 리소스 관리 및 자동화 |
| OpenStack | 클라우드 인프라 구조 및 환경 구축 |
| Kubernetes | 컨테이너 오케스트레이션 및 클러스터 구성 |
| CI/CD | 자동화된 실행 및 검증 파이프라인 |

## 학습 기록

- `01-Git-GitHub/` : Git 기본 개념 및 협업 실습
- `02-Sphinx-tox/` : 기술 문서 작성 및 빌드
- `03-Terraform/` : Terraform 기초 및 실습
- `04-OpenStack-Kubernetes/` : 클라우드 인프라 학습
- `05-Troubleshooting/` : 오류 원인 및 해결 과정

## 기록 방식

각 주제별로 다음 내용을 중심으로 정리합니다.

1. 학습 목표
2. 새롭게 알게 된 개념
3. 실습 과정 및 사용한 명령어
4. 발생한 오류와 해결 방법
5. 학습 결과 및 느낀 점
